# Contributing

Thanks for considering a contribution. Please open an issue first for large changes so the design and privacy impact can be discussed.

## Local development

- Use Node.js 20 or later.
- Install dependencies with `npm install`.
- Run `npm run check`, `npm test`, and `npm run build` before submitting.
- Keep uploaded story text, sharing URLs, OAuth tokens, and voice recordings out of logs, fixtures, screenshots, and issue attachments.
- Add tests for behavior changes and keep new services optional. The default reader must remain usable without a paid service or API key.
- Sign off every commit with `git commit -s`. The sign-off certifies the Developer Certificate of Origin (DCO): you wrote the contribution or have the right to submit it under this repository's AGPL-3.0-or-later license, and you agree to the DCO terms at https://developercertificate.org/.

## Pull requests

Describe the user problem, the behavior changed, the privacy/security implications, and the commands you ran. Do not include production credentials or copyrighted user documents. This project is licensed under AGPL-3.0-or-later; see `LICENSE`.
