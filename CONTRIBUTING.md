# Contributing

Thanks for considering a contribution. Please open an issue first for large changes so the design and privacy impact can be discussed.

## Local development

- Use Node.js 20 or later.
- Install dependencies with `npm install`.
- Run `npm run check`, `npm test`, and `npm run build` before submitting.
- Keep uploaded story text, sharing URLs, OAuth tokens, and voice recordings out of logs, fixtures, screenshots, and issue attachments.
- Add tests for behavior changes and keep new services optional. The default reader must remain usable without a paid service or API key.

## Pull requests

Describe the user problem, the behavior changed, the privacy/security implications, and the commands you ran. Do not include production credentials or copyrighted user documents. A project license has not yet been selected, so maintainers must resolve licensing before accepting contributions under a declared license.
