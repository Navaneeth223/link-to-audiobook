# Voice data and consent policy

The current build does not record, store, clone, import, export, donate, or upload a user's voice. Narration uses the browser or operating system SpeechSynthesis service. The browser may route speech through a system service according to its own settings.

Voice recording, profile creation, model-based voice generation, and community voice donation are not available. Any future implementation must obtain separate, explicit consent before recording, describe local and remote storage precisely, restrict profiles to the consenting speaker's own voice, include a workable export and deletion path, and have the recording and model licenses reviewed before release. This notice is a good-faith template and needs legal review before those features are introduced.
