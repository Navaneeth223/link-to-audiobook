# Voice data and consent policy

The current build does not record, store, clone, import, donate, or upload a user's voice. Narration can use the browser or operating system SpeechSynthesis service. Audiobook export can use the locally downloaded public Piper LibriTTS voice; this model is not a profile of the user and does not capture the user's voice.

This is a good-faith template, not legal advice. A qualified lawyer should review voice and biometric rules before launch. Contact: navaneethkv.dev@gmail.com.

Voice Studio and exports using a Voice Studio voice are not available. If Voice Studio is added later, it must require a verifiable consent record, permit export only of the user's own voice, and explain that users are responsible for rights in audio generated with their voice. Any future recording implementation must obtain separate, explicit consent before recording, describe local and remote storage precisely, restrict profiles to the consenting speaker's own voice, include a workable export and deletion path, and have the recording and model licenses reviewed before release. This notice is a good-faith template and needs legal review before those features are introduced.
