# Copyright and takedown

Private Story Reader is designed to process user-selected files in the browser. It is not a public document host and does not provide a public catalog of user stories. Shared Microsoft files are retrieved only through the configured, delegated access flow and remain subject to Microsoft's permissions.

If you believe the project itself distributes material that infringes your rights, contact the repository maintainer privately with the work identified, the relevant project URL or file path, your contact information, and a statement of authority to make the report. Do not include a copy of a private story or any OAuth credentials. The maintainer should publish a dedicated notice email and obtain jurisdiction-specific advice before operating a hosted service.
